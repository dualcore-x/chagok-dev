- 심사용 계정 초대는 필요 없음. 이미 초대했어도 같은 방법으로 제출

- 공개가 어려우면 소스와 APK 압축 파일의 다운로드 주소를 마감 전 메일로 보내도 됨
- 패드·마우스 전자서명, 서명 이미지 삽입 모두 인정. DOCX·PDF 모두 가능. 필수 항목과 순서만 지키면 글꼴·표·이미지는 자유
- 팀원 메일로 제출해도 되지만, 수정본은 처음 보낸 메일 주소로
- PPT·PDF·HTML 추가 자료 첨부 가능(심사 참고용), 영상·자료 분량 제한 없음
- 실차 불필요. README에 에뮬레이터 버전과 화면 규격을 적음. API 키 같은 비밀값은 저장소에서 빼도 됨
- 이미 접수한 팀은 최종 커밋 번호만 회신

**공모전 개발 범위 및 기술 문의 안내**
- 허용 SDK: Vehicle, NaviHelper, TextToSpeech, SpeechToText, FusedLocation. 차곡은 앞의 넷을 씀
- 음성 인식은 SpeechToText SDK만. 외부 음성 인식으로 보내는 방식은 안 됨(차곡은 ON_DEVICE STT)
- Pleos LLM SDK 미제공, 참가팀은 Gleo Interface 승인 신청 불가(필요하면 기획서에 향후 계획으로)
- 2차 PT는 에뮬레이터 시연, 실차 불필요. 운영사무국은 기술 문의에 답하지 않음
