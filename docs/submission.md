### 메일 초안

```text
제목: [차량용 앱 개발 공모전] 듀얼코어_[대표자명]

안녕하세요.
현대자동차그룹 차량용 앱 개발 공모전에 듀얼코어 팀으로 지원합니다.

- 앱명: 차곡
- 참가 부문: [일반(스타트업 포함) / 대학(원)생]
- 참가 인원: 2명 (팀원은 참조로 함께 보냅니다)

첨부
1. 접수양식(기획서) 및 개인정보 수집·이용 동의서 (대표자·팀원 서명 포함)
2. 시연 영상: [첨부 파일명 또는 링크]

개발 산출물
- GitHub 저장소(비공개): https://github.com/dualcore-x/chagok
  심사용 계정 [심사용 계정 이름]을 Collaborator로 초대해 두었습니다.
- APK: https://github.com/dualcore-x/chagok/blob/[태그]/apk/DualCore_Chagok_release.apk
- 테스트 환경: Pleos Connect Emulator v2.1.0. 실행 방법과 필요한 설정은 저장소 README에 있습니다.

감사합니다.
[대표자명] 드림
```

### 수정 제출이 필요할 때

- **처음 보낸 이메일 주소로** 다시 보냅니다. 마감 전 마지막 제출본이 최종본입니다.
- 제목: `[수정제출] [차량용 앱 개발 공모전] 듀얼코어_[대표자명]`
- 바뀐 것만이 아니라 **전체 자료와 서명한 동의서를 모두** 다시 첨부하고, 팀원 전원을 참조에 넣습니다.
