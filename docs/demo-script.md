# 시연 대본 초안 (B08)

초안 · 2026-11-05 앱 담당. 촬영·편집은 연동 담당(J10)이 맡습니다. 화면은 11/7 PR #22의 가로 2단 배치(왼쪽 숫자 요약·버튼, 오른쪽 목적지 칸·인계 목록) 기준입니다. 색은 에뮬레이터의 주간·야간 설정을 따르므로 촬영 전에 하나로 맞춥니다.

- 길이는 **2분 30초**를 팀 목표로 잡았습니다. 공식 제한이 아니라 팀에서 정한 길이입니다. 아래 시간은 선택 장면(장면 5)을 뺀 기준이고, 장면 5를 넣으면 15초 늘어 2분 45초가 됩니다.
- 촬영은 release APK로 합니다. debug 전용 개발 도구(시연 데이터, 시뮬레이션)는 쓰지 않습니다.
- 편집 순서는 로드맵의 **문제 → 인계 → 처리 → C에게 남은 일**을 따릅니다.
- 화면 문구는 `DemoScriptTest`가 앱과 같은지 검사합니다. 대본의 인용 문구를 고치면 테스트도 같이 고쳐주세요.

## 표기 원칙

| 구분 | 영상에서 표시하는 방법 |
| --- | --- |
| 실제 SDK 값 | 상단 "에뮬레이터 · 차량 데이터" 표시를 화면에 남긴다. 자막: "Pleos Connect 에뮬레이터에서 검증" |
| 수동 조작 | Virtual Console로 기어·주행거리를 바꾼 장면은 자막 "가상 콘솔로 주행 재현"을 넣는다 |
| 직접 확인 | 도착은 "도착했어요" 버튼으로 받는다. 화면 목적지 칸에 "도착 · 직접 확인"이 남는다. 자막: "에뮬레이터는 도착 신호를 재현하지 못해 직접 확인" |
| 미리 입력 | A의 인계 3건 중 2건은 촬영 전에 같은 화면에서 입력해 둔다. 자막 "촬영 전 같은 방식으로 입력" |

연출하지 않는 것:
- 글레오 호출 장면(승인과 실제 호출을 확인하기 전)
- 음성 입력(실제 Pleos STT로 "말로 남기기"를 시험하기 전)과 읽어주기(화면에 아직 연결하지 않음)
- 내비가 도착을 자동으로 알리는 장면(에뮬레이터에서 미검증)
- 관리자 웹(2차 계획). 마무리 장면에서 계획으로만 말한다.

## 촬영 전 준비

1. Pleos Connect Emulator를 cold boot하고 앱 데이터를 초기화합니다(`adb shell pm clear --user current com.dualcore.chagok`). Pleos 에뮬레이터는 앱이 사용자 10으로 돌아서 `--user current`를 빼면 데이터가 지워지지 않습니다. 기기 시계가 되돌아가면 "내용 바뀜"이 뜨지 않을 수 있습니다(`docs/architecture.md` 알려진 제약).
2. Virtual Console을 설정합니다. 숫자는 화면에 보이기 쉬운 값이면 됩니다.

   ```sh
   adb forward tcp:8088 tcp:8088
   tools/vc.sh gear Park
   tools/vc.sh odo 30000
   tools/vc.sh soc 80
   ```

   주행거리는 줄일 수 없습니다. 이미 30,000km보다 크면 `vc.sh`가 "console refused"를 출력하니, 에뮬레이터를 다시 켜고(cold boot) 넣습니다.

3. 프로필에서 **김하늘**로 사용을 시작하고 아래 2건을 입력합니다. **반납하지 않고** 그대로 두면 장면 1은 김하늘 화면에서 바로 시작합니다. 2번 뒤에 입력해야 두 건에도 주행거리 30,000km · 배터리 80%가 붙습니다.
   - 해야 할 일 · 물건 · 대상 장소 한빛상사: "트렁크의 샘플 박스 2개는 한빛상사 3층 구매팀 전달용이에요."
   - 참고 정보 · 장소 · 본사 주차장: "충전 케이블은 본사 주차장 B2 관리실 선반에 있어요."
4. 장면 1이 끝나면 장면 2를 찍기 전에 확인용 앱(`tools/probe`)의 `route` 명령(`requestRoute`)으로 **한빛상사** 경로 안내를 시작합니다. 경로는 장면 3 뒤에 지웁니다(장면 3의 7번).

## 장면별 대본

### 장면 0 · 문제 (0:00–0:20)

- **화면:** 공용차 키, 메신저 단체방, 대시보드에 붙은 메모지 같은 실사 컷이나 일러스트. 앱 화면은 아직 나오지 않습니다.
- **내레이션:** "회사 공용차는 하루에도 여러 사람이 바꿔 탑니다. 와이퍼 소리, 트렁크에 둔 샘플, 충전 케이블 위치. 앞사람이 알던 건 대개 단톡방이나 메모지에 남고, 다음 사람은 그걸 못 보고 출발합니다."

### 장면 1 · A가 반납하며 남긴다 (0:20–0:45)

- **화면:**
  1. 김하늘 화면에서 시작합니다(촬영 전 준비 3번).
  2. **인계 남기기**를 누르고 해야 할 일 · 차량 · **중요한 일로 표시**를 켠 뒤 "운전석 와이퍼에서 끽 소리가 나요. 정비 예약이 필요해요."를 화면에서 직접 입력합니다.
  3. "함께 남는 차량 상태: 주행거리 30,000km · 배터리 80%" 미리보기를 잠깐 보여줍니다.
  4. 저장 후 목록에서 미리 입력한 샘플 박스(물건 · 한빛상사)와 충전 케이블(참고 정보 · 본사 주차장)을 빠르게 훑습니다.
  5. **반납하기**
- **내레이션:** "차를 반납하면서 다음 사람이 알아야 할 걸 남깁니다. 해야 할 일인지 참고 정보인지, 차량·장소·물건 중 무엇에 관한 건지 고르면 됩니다. 남길 때의 주행거리와 배터리는 차에서 자동으로 붙습니다."
- **자막:** "주행거리·배터리: Pleos Vehicle SDK" / 4번에서 "촬영 전 같은 방식으로 입력"

### 장면 2 · B는 필요한 것만 받는다 (0:45–1:15)

- **화면:**
  1. 프로필에서 **이도윤** 선택
  2. 왼쪽 숫자 칸 "새로 받음 3 · 중요 1 · 목적지 일 1". (요약 문장은 화면에서 뺐고 core에 남아 `DemoScriptTest`가 검사합니다.)
  3. 오른쪽 맨 위 "이번 목적지" 칸의 **내비 목적지** 표시와, 바로 아래 "이번 목적지 · 한빛상사" 섹션의 샘플 박스(새 인계는 파란 테두리)
  4. "새로 받은 인계"에서 와이퍼(새 인계 · 중요)와 충전 케이블에 각각 **확인했어요**
- **내레이션:** "다음 운전자는 이름만 고르면 됩니다. 처음 보는 것과 바뀐 것만 짧게 요약하고, 내비에 찍힌 목적지에서 할 일을 맨 앞에 올립니다. '확인했어요'는 봤다는 기록일 뿐, 일이 끝났다는 뜻은 아닙니다."
- **자막:** "목적지: Pleos NaviHelper SDK"

### 장면 3 · 목적지에서 끝내고 반납한다 (1:15–1:50)

- **화면:**
  1. `tools/vc.sh gear Drive` → Pleos의 "주행 중에는 사용할 수 없습니다" 화면이 잠깐 나옵니다.
  2. 주행거리를 조금 올린 뒤 `tools/vc.sh gear Park` → 앱으로 돌아옵니다.
  3. **도착했어요** → 대화상자 "한빛상사에 도착했어요" → 샘플 박스의 **처리 완료로 기록**
  4. 처리 메모 "구매팀 김OO님께 전달" → **완료**
  5. 충전 케이블 **고치기** → "충전 케이블은 본사 주차장 B1 경비실로 옮겼어요." → 저장
  6. **반납하기** → "진행 중인 일 1건은 다음 운전자에게 그대로 넘어가요."
  7. (편집에서 자름) **경로 안내를 끝냅니다.** 에뮬레이터에서는 도착 신호가 오지 않아 경로가 계속 살아 있고, 그대로 두면 장면 4에서 박서연 화면에도 "내비 목적지 · 한빛상사"가 나옵니다.
     - 2026-11-10 촬영에서는 확인용 앱의 `cancel`(`cancelRoute`)로 경로가 지워지지 않았습니다(두 번 시도).
     - 내비 화면의 **안내 종료** 버튼도 adb 탭에 반응하지 않습니다.
     - 대신 `adb shell am force-stop ai.umos.maps.android.navigation.app`로 내비를 끄고 독에서 다시 열면 "경로 안내 재시작" 창이 뜹니다. 여기서 **안내 종료**를 누르면 지워집니다(adb 탭으로도 됨).
     - 차곡으로 돌아와 10초 안에 목적지 칸이 "어디로 가나요?"로 바뀌었는지 보고 넘어갑니다.
- **내레이션:** "주행 중에는 화면을 쓰지 않습니다. 목적지에 도착해 주차하면 그곳에 남겨진 인계를 다시 알려주고, 끝낸 일은 운전자가 직접 처리 완료로 남깁니다. 주차만 했다고 알리지는 않습니다. 케이블 위치가 바뀐 것도 바로 고쳐둡니다."
- **자막:** "가상 콘솔로 주행 재현" / "에뮬레이터는 도착 신호를 재현하지 못해 직접 확인"

- **화면:**

### 장면 5 (선택) · 처음 남긴 사람에게도 바뀐 것만 (+0:15)

- **화면:** 박서연 반납 → **김하늘** 다시 선택 → 충전 케이블에 **내용 바뀜** 태그, 와이퍼는 "계속 남은 중요한 일"(계속 남은 일 태그)
- **숫자 칸:** "새로 받음 1 · 중요 1" (바뀐 케이블 1건, 계속 남은 와이퍼 1건)
- **내레이션:** "처음 남긴 사람도, 남이 고친 내용은 다시 받고, 아직 안 끝난 중요한 일은 계속 따라옵니다."
- 기본 대본에는 넣지 않습니다. 앞 장면이 짧게 찍혀 15초가 남을 때만 장면 4 뒤에 넣습니다.
